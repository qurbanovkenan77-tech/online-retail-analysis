**Proposed analytical definitions**

First, define an eligible merchandise population: valid records with positive prices, excluding agreed non-product entries and applying the duplicate policy you select.

Within that same population:

| Metric | Definition |
|---|---|
| Recorded positive sales value, **S** | Sum of `Quantity × UnitPrice` where quantity is positive and invoice is not C-prefixed |
| Cancellation value, **C** | Sum of `abs(Quantity) × UnitPrice` for C-prefixed, negative-quantity rows |
| Other negative value, **A** | Absolute value of negative-quantity rows without a C prefix |
| Net recorded merchandise value | **S − C − A** |
| Cancellation-value rate | **C ÷ S × 100** |
| Product/country sales share | Group positive sales value ÷ total positive sales value |

If sales are zero, the rate should be unavailable rather than reported as 0%.

**The cancellation-value rate is a value ratio, not the percentage of orders cancelled.** We would not match cancellations to original purchases. A cancellation recorded this month may relate to an earlier purchase, including one outside the dataset.

Similarly, negative quantities do not establish physical returns. They may represent cancellations or adjustments; the dataset does not tell us whether goods were physically returned or why.

**Data-handling choices and tradeoffs**

- **Missing customer IDs:** Keep these records in product, country, cancellation, and monthly analysis. Exclude them only from customer analysis. Report the percentage of eligible sales value associated with known customers so readers understand customer-analysis coverage.
- **Missing descriptions:** Keep otherwise eligible records and group products by `StockCode`. Use an available description for that code as a display label, or the code itself if no description exists.
- **Duplicates:** My recommendation is to remove exact duplicates across all eight original columns, retain the first, and report the effect on sales and cancellations. However, identical lines might represent legitimate repeated entries because there is no unique line ID. Deduplication must be described as an assumption, not a proven correction.
- **Invalid prices:** Exclude negative prices from monetary analysis. Report zero-price rows separately and exclude them from paid-purchase metrics; we cannot assume whether they are freebies or errors.
- **Unusual quantities:** Retain large quantities unless there is specific evidence of an error. Flag the largest absolute line values for review instead of imposing an arbitrary cutoff.
- **Non-product entries:** Use a small, documented code list for clear charges and adjustments. Keep ambiguous entries such as “Manual” separate pending review. Do not remove every alphabetic stock code—the workbook contains actual products with those codes.
- **Auditability:** Produce a cleaning summary with counts and value effects. Use an ordered exclusion process so overlapping problems do not double-count removed rows.

My recommendation is to make the headline analysis **merchandise-only**, with excluded charges and ambiguous entries documented separately. The alternative is an all-entry analysis, but postage and accounting adjustments could then appear among the “top products.”
